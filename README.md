# SMORPHILA - Software for MORPHometric Image Landmark Acquisition

SMORPHILA is a software for the acquisition and preprocessing of landmark-based morphometric data from two-dimensional images.

![license](https://img.shields.io/pypi/l/smorphila)
[![PyPI version](https://img.shields.io/pypi/v/smorphila.svg)](https://pypi.org/project/smorphila/)

In addition to standard landmark-acquisition functions, SMORPHILA allows the geometric standardization of articulated
structures by rotating segments to predefined orientations while preserving their lengths and connectivity.
